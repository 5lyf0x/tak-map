# TAK Map 1.4.0 i618 installation or upgrade

Assuming `tak-map-v1.4.0-i618.zip` is in `~/Downloads`:

```bash
cd ~/Downloads
unzip -o tak-map-v1.4.0-i618.zip
cd ~/Downloads/tak-map-v618
chmod +x install.sh
sudo ./install.sh
cd ~/Downloads
```

After installation, close and reopen TAK Map and hard-refresh the browser.

Do not delete the extracted `~/Downloads/tak-map-v618` install folder after installation.
