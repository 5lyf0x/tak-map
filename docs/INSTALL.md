# TAK Map Installation

Current package: **1.4.0 i635**

Assuming `tak-map-v1.4.0-i635.zip` is in `~/Downloads`:

```bash
cd ~/Downloads
mkdir -p tak-map-v635
unzip -o tak-map-v1.4.0-i635.zip -d tak-map-v635
cd tak-map-v635
chmod +x install.sh
sudo ./install.sh
cd ~/Downloads
```

After installation, close and reopen TAK Map and hard-refresh the browser.

Do not delete the extracted `~/Downloads/tak-map-v635` install folder after installation.
