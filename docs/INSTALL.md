# TAK Map 1.4.0 i620 installation or upgrade

Assuming `tak-map-v1.4.0-i620.zip` is in `~/Downloads`:

```bash
cd ~/Downloads
unzip -o tak-map-v1.4.0-i620.zip
cd ~/Downloads/tak-map-v620
chmod +x install.sh
sudo ./install.sh
cd ~/Downloads
```

After installation, close and reopen TAK Map and hard-refresh the browser.

Do not delete the extracted `~/Downloads/tak-map-v620` install folder after installation.
